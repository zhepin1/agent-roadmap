# agent-roadmap

> 大二学生冲刺 AI Agent 方向实习的 26 周学习仓库。

## 目标

系统性地掌握 AI Agent 应用开发（含 RAG / 知识库），用 2–3 个完整可部署的项目积累生产级经验，最终在 2028 年（大三下）拿到大厂暑期实习，并沿途争取日常实习 / 远程实习 / 开源贡献。

## 学习节奏（26 周 / 6 阶段）

| 阶段 | 周次 | 主题 | 关键产出 |
|---|---|---|---|
| 1 工程地基 | 1–4 | Python + Git + HTTP + SQL | 一个调用公开 API 的小工具 |
| 2 大模型与提示词 | 5–8 | Prompt 工程 + 评测意识 | 同一需求 5 版 Prompt，50 条样本准确率统计 |
| 3 Agent 核心 | 9–13 | 手写 Agent Loop（不用框架） | 200 行纯 Python Agent，含错误恢复 |
| 4 检索与记忆 | 14–18 | RAG + 溯源 | 用专业课真实文档做带引用的问答 |
| 5 框架与多智能体 | 19–24 | LangGraph + 评测 + MCP | 多智能体工作流 + 自己的 MCP Server |
| 6 作品化与投递 | 20 周起并行 | 简历 + 项目展示 + 投递 | 三个项目整理上线，边投边补 |

## 技术栈

- 语言：Python 3.12
- 版本控制：Git + GitHub
- 大模型：国产 API（DeepSeek / 通义 / 豆包）
- 框架（后期）：LangGraph、FastAPI、Docker

## 提交约定

- 每完成一个小功能就 commit 一次（本机快照）
- 每天 push 到 GitHub 保持绿点连续
- commit message 用中文简述做了什么
